# Old Quarter: continuous scenery and shared architecture

The isometric and first-person cameras now use the same district identity and the same eight authored facade textures, with two lighting faces. The old first-person view replaced those buildings with one generic window/door shader; now the original ROM textures are sampled directly. Potheads keeps its physical fascia, and distant brick and window colors are subdued without adding new assets or a palette. Wall heights and floor occlusion geometry remain unchanged on the first-person path.

The isometric camera now pans through the four existing movement phases, translating terrain, building walls/roofs, props, route cues and cutaways together. Danny remains centered and the original fractional world depth governs painter order. First-person uses the same fixed-point world position. Map, collision, routes, story timings and SRAM are unchanged.

Billboard occlusion no longer redraws overlapping walls one column at a time. Equal ray spans reuse the already computed shades, including cold camera frames. No second buffer or expanded texture cache is added.

Host tests retain the independent 3,456 shipped first-person golden frames in a host-only legacy-art mode. The new visual path is separately compared against the original one-column restoration algorithm, tests cold/warm equivalence, and verifies the shared facade source texels. The projection regression checks the original district dimensions and each fractional phase against the exact world position. Existing clipped sprite and player-readability checks still run. No hardware/emulator performance or visual completion claim until the pending build and capture succeed.

The follow-up resolves facade U coordinates at the actual crossed wall plane (including diagonal two-edge ray steps) instead of sampling every wall as though it faced the camera. The isometric easel also uses that painter. The legacy shader and one-column restoration remain available only in host golden tests. New tests check physical wall-plane UVs and all five creative-stage appearances at several distances. CI remains the cartridge/IWRAM/emulator gate.

CI identified a signed-integer promotion warning in the previously queued motion-continuity pass; explicitly unsigned tick differences fix it without altering any pose. The current follow-up also admits first-person objects if any part of their projected width is visible, rather than rejecting the entire object when its center is hidden. Admission and cached wall restoration share a conservative radius. The host golden path retains its historical center test. A new independent visibility interval regression covers screen-edge clipping, hidden centers and visible slivers. The build remains the final verification gate.

## Pixel-exact floor and wall cache acceleration
The verified e6bdd68 cartridge presented 29.565 FPS for the opening, 14.932 stationary first-person and 7.167 walking. The next optimization removes repeated stationary ray traversal and computes the floor using incremental Q8 coordinates and continuous visible spans. The cardinal camera has one varying coordinate per floor row. Pretransposed two-bit road columns cost 15,360 ROM bytes; all 61,440 original categories are reproduced exactly. The floor projection table costs 360 ROM bytes; no new framebuffer or runtime texture RAM. Both walking and stationary geometry are unchanged. Host-only reference floor and historical scenery modes keep the original 3,456 golden frames and additionally compare 1,152 coherent full frames against the prior per-ray floor/column restoration path. The source generator is checked byte-for-byte in CI. No measured GBA speed increase is claimed until the updated capture completes.

## Exact boundary-crossing ray paths
Verified 8e519755 at 19.909 stationary and 8.660 walking page flips/s in mGBA, versus 14.932 and 7.167 previously. Opening held 29.565. Next pass packs the original 75-sample ray march into translation-invariant crossing sequences: 1,472 indices, 1,064 distinct paths and 14,490 path bytes (17,434 bytes total). Signed coordinate reflection preserves original integer tile crossings, including simultaneous corner entries. Quarter-tile movement and settled positions use the compressed paths; arbitrary fractional coordinates fall back to the original march. Actual hit steps and tile coordinates retain the previous 2300-depth clamp and UV projection. A 72-byte table replaces recurring wall-height divisions. Host tests compare every map position (including edges), all quarter-tile origins, 45 directions and four headings to the original ray marcher, and compare the coherent rendered frames against reference floor/ray/occlusion paths. Runtime IWRAM budget and GBA cadence remain mandatory CI gates. No unmeasured FPS gain claimed.
