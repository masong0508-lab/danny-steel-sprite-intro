# Danny Steele — music workstation
Visit the music desk in the east plaza. START then A opens the destination list; choose Music Studio and follow its waypoint. Recover the demo on the first visit, then A at the desk opens the music choices. Basic Studio offers Song, Notes, Mixer and Live. START saves one of four takes; Advanced unlocks Order and Lyrics as well. Listen at the completed desk plays the actual saved arrangement. The song-sharing scene with Mara uses the same sequence.
| Page | Function |
|---|---|
| Song | Tempo and instrumental feel |
| Notes | Eight-step melody; A toggles rests |
| Order | Four phrase variants (advanced) |
| Lyrics | Text cue cards, not vocal recordings (advanced) |
| Mixer | Lead, keys, bass, drums; select channel and adjust OFF/LOW/MID/HIGH. A mutes/unmutes. |
| Live | Preview the actual GBA PSG sequence. |
L/R switches pages, LEFT/RIGHT selects, UP/DOWN edits, SELECT plays/stops, B exits. START saves a take in Basic; after the master is complete START returns to pause. The editor stops sound rather than substituting a background tune; changes are saved on leaving. Four track levels are packed into the existing 24-byte SRAM extension. Version 1 imports the melody, phrases, tempo, feel and lyric and maps its former instrumental harmony setting to keys on/off. Version 2 stores the mixer. Neither change affects the original authored soundtrack or ending music. No sampled vocals, microphone recording or audio export is implied.
